# 🎮 Kids Project – Unity Game Logic Showcase (Client Project – Code Only)

🚸 This repository contains the **core C# scripts** of an educational game developed in Unity for a commercial client.  
The full project includes multiple mini-games designed to support cognitive development for young children.

🧠 **What’s included:**
- All gameplay logic and scene transitions
- Level progression and mini-game management
- Audio system (background music + SFX handling)
- UI flow (win panels, star animations, navigation)
- Well-organized, modular codebase

🎮 **Mini-Games (4 in total):**
1. **Color Sorting** – Players sort colored objects into their corresponding groups.
2. **Shape Matching** – Players match silhouettes with predefined shapes.
3. **Puzzle** – A traditional sliding puzzle game to encourage problem-solving skills.
4. **Coloring** – Players can color black-and-white images, helping with creativity and color recognition.

❌ **What’s not included:**
- No assets (graphics, sounds, animations) due to client confidentiality  
- No full Unity project files – this is a code-only showcase
